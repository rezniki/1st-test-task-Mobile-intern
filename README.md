# 📋 Task Manager App

Мобильное приложение для управления задачами полевых сотрудников. Разработано на React Native (Expo) в рамках тестового задания. Приложение оптимизировано для быстрого ввода данных, работы без интернета и интуитивного использования "в поле".

## 🚀 Быстрый старт

Для локального запуска вам понадобятся:
- Установленный [Node.js](https://nodejs.org/) (версия ≥ 18)
- Приложение [Expo Go](https://expo.dev/client) на смартфоне (Android/iOS)
- Стабильное Wi-Fi соединение (телефон и компьютер должны быть в одной сети)

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/task-manager-app.git
cd task-manager-app

# 2. Установите зависимости
npm install --legacy-peer-deps

# 3. Запустите Metro Bundler
npx expo start

# 4. Отсканируйте QR-код в приложении Expo Go на вашем устройстве
```

## Примечание: Флаг --legacy-peer-deps используется для обхода конфликтов версий зависимостей в Expo SDK 54. Не удаляйте его при установке.

## ✨ Реализованный функционал

✅ CRUD операции: Создание, просмотр, редактирование и удаление задач

✅ Статусы задач: Переключение между In Progress, Completed, Cancelled

✅ Сортировка: По дате создания (↑/↓) и по текущему статусу

✅ Валидация: Проверка обязательных полей, формата даты и длины текста

✅ Оффлайн-режим: Все данные сохраняются локально и доступны без интернета

✅ Адаптивный UI: Крупные тач-таргеты, чёткая типографика, минималистичный дизайн


## 📖 Как пользоваться приложением

1. Главный экран
   
Открывается список задач. Вверху расположен переключатель сортировки. Потяните список вниз для обновления.

2. Создание задачи

Нажмите кнопку + в левом верхнем углу. Заполните форму:

📝 Заголовок (обязательно, мин. 3 символа)

Дата и время выполнения (нельзя выбрать прошедшую дату)

📍 Адрес (ручной ввод, обязательно)

Описание (опционально)

Нажмите Сохранить. Задача появится в списке.

3. Просмотр деталей
   
Тапните по любой задаче в списке, чтобы открыть экран с полной информацией, текущим статусом и кнопками действий.

4. Изменение статуса

На экране деталей или в списке нажмите на бейдж статуса. Выберите новый статус из выпадающего списка. Изменение применяется мгновенно.

5. Редактирование и удаление

🖊️ Редактирование: Нажмите иконку карандаша. Откроется форма с предзаполненными данными.

🗑️ Удаление: Нажмите иконку корзины. Появится диалог подтверждения для предотвращения случайного удаления.

6. Сохранение данных

Приложение автоматически сохраняет все изменения в памяти устройства. Данные не пропадают при закрытии приложения или перезагрузке телефона.
